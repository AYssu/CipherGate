# 登录

## 开发者后台

从平台首页或 `/login` 进入。登录成功后进入 `/dashboard`，按角色显示应用管理、用户中心、系统管理、插件和文档等菜单。

若提示 `401 未登录`，通常是 token 失效、请求未携带登录态或会话已过期；重新登录后重试。若提示 `403 权限不足`，请让管理员检查角色、菜单权限和 API 权限，而不是修改前端路由。

## Portal 应用用户

从首页的「应用用户登录」或 `/portal/` 进入：

1. 获取图形验证码并填写账号、密码。
2. 有多个应用时进入应用选择页，选择要使用的应用。
3. 登录后进入 `/portal/dashboard`。

Portal 会保存当前应用上下文，会员、订单、充值和设备信息均与该应用绑定。

## 密码找回

Portal 用户可通过 [密码找回](/portal/password-recovery) 通过邮箱验证码重置指定应用的密码。开发者和管理员账号的密码重置由管理员在用户管理中处理。

## 登录异常

- 账号不存在：确认账号所属应用和邮箱。
- 验证码错误：重新获取验证码，注意区分图形验证码和邮箱验证码。
- 会员过期：Portal 可登录，但第三方 WebSocket 登录可能被拒绝，详见 [API 对接](/developer/api-integration)。
- 权限不足：请管理员检查角色/API 权限和菜单授权。
