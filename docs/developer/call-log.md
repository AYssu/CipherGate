# 调用日志

调用日志记录了应用的所有 API 调用信息，用于监控和排查问题。

## 功能列表

| 功能 | 说明 |
|------|------|
| 查看日志 | 查看 API 调用记录 |
| 筛选日志 | 按条件筛选日志 |
| 导出日志 | 导出日志到文件 |
| 日志详情 | 查看单条日志详情 |

## 日志字段

| 字段 | 说明 |
|------|------|
| 请求时间 | API 调用时间 |
| 请求方法 | GET、POST 等 |
| 请求路径 | API 路径 |
| 请求参数 | 请求的参数 |
| 响应状态 | 成功/失败 |
| 响应时间 | API 响应耗时 |
| 客户端 IP | 请求来源 IP |
| 用户标识 | 调用用户 |

## 筛选条件

- 时间范围
- 请求方法
- 响应状态
- 用户标识
- IP 地址

## 使用场景

- 监控 API 使用情况
- 排查接口问题
- 分析用户行为
- 统计调用量

## 最佳实践

::: tip 建议
- 定期检查异常调用
- 关注高频调用接口
- 监控响应时间异常
:::
