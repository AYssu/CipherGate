# 签到

每日签到可以获得奖励，连续签到有额外奖励。

## 签到规则

| 规则 | 说明 |
|------|------|
| 每日签到 | 每天可签到一次 |
| 签到时间 | 每日 0:00 重置 |
| 奖励内容 | 余额、积分或会员时长 |

## 连续签到奖励

| 连续天数 | 奖励 |
|----------|------|
| 1 天 | 基础奖励 |
| 3 天 | 基础奖励 × 1.5 |
| 7 天 | 基础奖励 × 2 |
| 14 天 | 基础奖励 × 3 |
| 30 天 | 基础奖励 × 5 |

## 签到历史

- 查看签到记录
- 统计签到天数
- 查看获得的奖励

## 最佳实践

::: tip 建议
- 坚持每日签到获取最大奖励
- 设置签到提醒避免忘记
- 查看签到历史了解奖励情况
:::
