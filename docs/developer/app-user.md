# 终端用户管理

终端用户是应用内的账号用户，与卡密用户分开管理。用户可以绑定多个设备，并通过 HTTP 账号密码登录、WebSocket 或 Portal 使用应用。

## 用户信息

可维护用户名、邮箱、手机号、昵称、头像、签名、密码和会员到期时间。列表还展示：

- 登录次数、最后登录时间/IP/归属地。
- 最后登录设备标识。
- WebSocket 在线状态、会话数和在线时长。
- 会员状态、试用状态及到期时间。
- 是否存在被封禁设备。

## 不接入 WS 的账号客户端

调用 [`POST /api/v1/user/login`](/developer/api-integration#http-账号密码登录)，提交加密后的用户名或邮箱、密码和设备标识即可。签名与加密沿用应用配置，不需要先连接 WS；返回用户身份、会员状态、绑定数和变量，不签发心跳 token。

收费应用校验会员有效期，免费应用只跳过会员期限检查，仍要求正确账号密码。已有匿名免费模式和卡密登录接口保持不变。

HTTP 成功登录会更新用户登录次数、最后登录信息和设备绑定，也会进入首页登录统计。用户列表在登录后 **5 分钟**显示“HTTP 近期在线”，支持综合在线筛选和首页按用户去重统计。再次成功登录刷新窗口；它**不会**将用户标为 WS 在线、生成虚假的在线时长，或顶掉已连接的 WS 会话。

## 设备绑定

绑定记录包含设备 ID、设备名称、系统、IP、绑定类型、使用次数和最后活跃时间。账号绑定与卡密绑定可能共用设备，发生冲突时第三方 HTTP / WebSocket 登录会返回 `DEVICE_CONFLICT`。

## 常用操作

- 创建、修改、删除用户和重置密码。
- 延长会员时长，支持批量操作。
- 封禁或解封用户、设备，并填写原因。
- 强制断开用户的 WebSocket 会话。
- 解绑设备；被软删的设备在用户重新登录时可能按服务端规则恢复。

## 自助查询

[终端用户自助查询](/self-service/app-user) 用于用户查看会员到期和绑定状态。自助页面只展示有限信息，不提供管理员级解绑和封禁操作。

## 用户迁移与复制

在「应用管理 → 用户迁移」中，将选定账号复制或迁移到其他应用。操作需要 `APP_USER_TRANSFER` 权限，并同时具备源、目标应用的所有者或管理员权限。

迁移前必须预检查并显式确认；会员到期时间按源账号替换，不累加时长。设备封禁和已领取试用限制按规则保留，订单、卡密和历史流水不跨应用搬运。步骤、冲突规则和管理接口见 [用户迁移与复制](/developer/user-transfer)。
