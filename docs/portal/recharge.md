# Portal 充值

**入口：** `/portal/recharge` · **适用对象：** 已登录的应用终端用户

充值页展示当前应用启用的会员方案，包括方案名称、价格、有效天数或永久类型。方案由应用方维护，与平台余额页的配额商品分别管理。

## 购买流程

1. 选择一个会员方案，点击「购买」。
2. 在确认窗口核对订单号、方案名称和金额。
3. 点击「去支付」，进入支付渠道页面完成付款。
4. 返回 [订单记录](/portal/order) 和 [会员信息](/portal/membership)，核对到账结果。

没有支付跳转地址时，页面会提示前往订单记录查看。支付渠道页面显示成功后，仍应确认平台订单和会员状态。

## 结果处理

| 状态 | 下一步 |
| --- | --- |
| 订单已支付，会员已更新 | 本次购买完成 |
| 已付款，平台状态尚未更新 | 稍后刷新；持续异常时向应用方提供订单号和支付凭证 |
| 订单仍待支付 | 核对是否实际付款，避免重复下单付款 |
| 暂无可购买方案 | 联系应用方确认方案是否已启用 |

创建订单还需应用开放 Portal 支付，并启用该应用的支付网关配置；支付回调地址也需与实际部署地址一致。Portal 当前提供购买和订单查询；退款或发票需求请联系应用方处理。

## 加载失败与重复操作

购买方案加载失败时，页面显示「重新加载」；只有成功获取到空列表时才显示「暂无可购买方案」。请求创建订单或支付确认窗口打开期间，其他购买按钮暂时禁用。

「稍后支付」只关闭确认窗口，已经创建的待支付订单仍保留。超时或断网后，先通过「查看订单记录」核对是否已创建订单，再决定是否重试。
