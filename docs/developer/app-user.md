# 终端用户管理

终端用户是使用您应用的最终用户，您可以在这里管理所有用户账号。

## 功能列表

| 功能 | 说明 |
|------|------|
| 查看用户列表 | 查看所有注册用户 |
| 创建用户 | 手动创建用户账号 |
| 编辑用户 | 修改用户信息 |
| 删除用户 | 删除用户账号 |
| 封禁/解封 | 封禁或解封用户 |
| 重置密码 | 重置用户密码 |
| 延长会员 | 延长用户会员时长 |
| 查看设备 | 查看用户绑定的设备 |
| 强制下线 | 强制用户下线 |

## 用户列表

### 查看用户

1. 登录开发者后台
2. 点击左侧菜单「应用管理」→「终端用户管理」

### 列表字段

| 字段 | 说明 |
|------|------|
| 用户名 | 用户的登录名 |
| 昵称 | 用户的显示名 |
| 邮箱 | 用户的邮箱 |
| 手机号 | 用户的手机号 |
| 所属应用 | 用户所属的应用 |
| 绑定设备 | 用户绑定的设备数量 |
| 封禁状态 | 是否被封禁 |
| 会员状态 | 会员是否有效 |
| WS 在线 | 是否在线 |
| 登录次数 | 累计登录次数 |
| 最后登录 | 最后登录时间 |

### 筛选和搜索

支持按以下条件筛选：

- 用户名
- 邮箱
- 手机号
- 封禁状态
- 会员状态
- 在线状态

## 创建用户

### 步骤 1：点击创建

1. 在用户列表页面
2. 点击「创建」按钮

### 步骤 2：填写信息

| 字段 | 说明 | 必填 |
|------|------|------|
| 所属应用 | 选择应用 | ✅ |
| 用户名 | 3-20 个字符 | ✅ |
| 密码 | 至少 6 位 | ✅ |
| 邮箱 | 有效邮箱地址 | ❌ |
| 手机号 | 有效手机号 | ❌ |
| 昵称 | 用户显示名 | ❌ |
| 会员到期 | 设置会员到期时间 | ❌ |

### 步骤 3：确认创建

1. 点击「确定」按钮
2. 用户创建成功

## 用户操作

### 封禁用户

1. 在用户列表找到目标用户
2. 点击操作列的「更多」按钮
3. 选择「封禁」
4. 确认封禁操作

::: warning 注意
封禁后用户将无法登录和使用应用
:::

### 解封用户

1. 在用户列表找到目标用户
2. 点击操作列的「更多」按钮
3. 选择「解封」
4. 确认解封操作

### 重置密码

1. 在用户列表找到目标用户
2. 点击操作列的「更多」按钮
3. 选择「重置密码」
4. 输入新密码
5. 确认重置

### 延长会员

1. 在用户列表找到目标用户
2. 点击操作列的「更多」按钮
3. 选择「延长会员」
4. 选择时间单位和数值
5. 确认延长

### 查看设备

1. 在用户列表找到目标用户
2. 点击操作列的「更多」按钮
3. 选择「查看设备」
4. 查看用户绑定的设备列表

### 强制下线

1. 在用户列表找到目标用户
2. 点击操作列的「更多」按钮
3. 选择「下线」
4. 确认下线操作

::: tip 提示
强制下线会立即断开用户的 WebSocket 连接
:::

## 批量操作

支持批量操作多个用户：

1. 勾选需要操作的用户
2. 在批量操作下拉框中选择操作
3. 点击「确定」按钮

支持的批量操作：
- 批量加时
- 批量扣时
- 批量下线
- 批量封禁
- 批量解禁
- 批量删除
