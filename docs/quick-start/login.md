# 登录

平台后台和应用 Portal 使用不同账号体系。平台账号用于管理应用与平台资源，Portal 账号用于使用某个应用。

## 平台后台

入口为平台首页或 `/login`。

| 登录方式 | 使用条件 |
| --- | --- |
| GitHub 授权 | 管理员已完成 GitHub OAuth 配置 |
| 平台密码 | 账号已设置平台密码，使用 GitHub 账号名与平台密码 |

GitHub 用户可先授权登录，再在个人资料中设置平台密码。登录成功后进入 `/dashboard`；可用功能取决于角色、菜单及 API 权限。

## 应用 Portal

入口为首页的应用用户入口或 `/portal/login`。

1. 输入应用用户的邮箱、密码和图形验证码。
2. 邮箱关联多个应用时，按提示选择应用。
3. 进入 `/portal/dashboard`，核对当前应用。

会员、订单、充值和设备数据归属于所选应用。通过应用注册链接创建的账号不能用于平台后台登录。

## 密码找回

应用用户通过 [Portal 密码找回](/portal/password-recovery) 的邮箱验证码流程重置指定应用的密码。平台账号无法通过该入口找回；可以使用 GitHub 授权登录后修改密码，或联系平台管理员。

## 登录异常

| 现象 | 处理方式 |
| --- | --- |
| 邮箱或密码错误 | 确认使用了正确的账号体系，必要时找回应用密码 |
| 验证码错误或过期 | 刷新图形验证码；邮箱验证码应在对应操作中使用 |
| 请求返回 `401` | 重新登录后重试 |
| 请求返回 `403` | 管理员核对角色、菜单和 API 权限 |
| 会员过期 | 检查应用会员；Portal 登录与第三方客户端的会员校验规则不同 |
