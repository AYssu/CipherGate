# 应用管理

应用是 CipherGate 的核心概念，每个应用代表一个独立的授权管理单元。

## 功能列表

| 功能 | 说明 |
|------|------|
| 创建应用 | 新建应用并配置基本信息 |
| 编辑应用 | 修改应用名称、描述等配置 |
| 删除应用 | 删除应用（需确认） |
| 查看详情 | 查看应用详细信息和统计数据 |

## 创建应用

### 步骤 1：进入应用列表

1. 登录开发者后台
2. 点击左侧菜单「应用管理」→「应用列表」

### 步骤 2：点击创建

1. 点击页面右上角「创建」按钮
2. 填写应用信息

### 步骤 3：填写应用信息

| 字段 | 说明 | 必填 |
|------|------|------|
| 应用名称 | 应用的显示名称 | ✅ |
| 应用描述 | 应用的详细描述 | ❌ |
| 应用图标 | 应用的图标（可选） | ❌ |

### 步骤 4：完成创建

1. 点击「确定」按钮
2. 应用创建成功后会显示在列表中

## 应用配置

创建应用后，您可以进行以下配置：

### 基本配置
- 应用名称、描述、图标
- 应用状态（启用/禁用）

### 安全配置
- 访问权限设置
- IP 白名单
- API 限流配置

### 通知配置
- 邮件通知设置
- Webhook 配置

## 应用链接

每个应用都有专属的链接：

| 链接类型 | 用途 | 格式 |
|----------|------|------|
| 注册链接 | 邀请用户注册 | `/register?id=应用ID` |
| 用户查询 | 查询用户信息 | `/app-user?id=应用ID` |
| 卡密激活 | 用户激活卡密 | `/license?id=应用ID` |

## 最佳实践

::: tip 建议
- 应用名称简洁明了，便于识别
- 填写详细的应用描述，方便用户了解
- 定期检查应用统计数据
:::

::: warning 注意
- 删除应用前请确认已备份重要数据
- 应用删除后无法恢复
:::
