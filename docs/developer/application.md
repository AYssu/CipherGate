# 应用管理

应用是卡密、终端用户、变量、插件和第三方凭证的归属边界。

## 基础信息

创建应用时维护应用名称、描述、分类、标签和图标。创建后系统生成：

- `appKey`：对外接入标识。
- `appSecret`：参与 HMAC 签名，不能下发给不可信客户端。
- 应用状态：启用或停用。停用后相关第三方接口会拒绝请求。

AppSecret 可重置。重置后旧签名立即失效，所有客户端都必须同步更新密钥。

## 业务与安全配置

| 配置 | 说明 |
| --- | --- |
| 业务模式 | 决定应用采用的业务规则 |
| 加密插件 | 选择 `aes-default` 或已安装的 PF4J 加密插件 |
| 加密配置 | 按插件模板填写 JSON 配置；保存前校验字段是否匹配 |
| 流量限制 | 限制应用可用流量；页面同时展示已用量 |
| 换绑扣时 | `NONE`、百分比或固定小时；卡密换绑时按配置扣减到期时间 |
| 换绑冷却 | 0 表示不限制，其他值表示两次换绑之间的冷却小时数 |

## 版本、公告与更新包

- `当前版本`：客户端当前版本基线。
- `最低版本`：客户端允许运行的最低版本。
- `应用公告`：公告接口返回的全文。
- `更新说明`：更新检查接口返回的更新文案。
- `更新包`：上传后写入对象存储，由更新检查返回临时下载凭据。

详细接口行为见 [第三方 API 对接](/developer/api-integration)。

## Portal 支付

应用可单独开启或关闭终端用户 Portal 支付，并配置支付成功后的返回地址。支付能力和实际支付渠道还受系统配置、配额产品及应用配置共同影响。

## 应用代理

应用代理是绑定到平台用户的细分权限账号，可以配置：

- 数据范围：仅本人数据或应用全部数据。
- 卡密和终端用户的查看、创建、修改、删除、查看全部权限。
- 按卡密类型设置可创建数量额度。
- 启用状态和备注。

代理不会替代应用所有者权限；删除或停用代理前应确认其是否仍有未完成的运营任务。
