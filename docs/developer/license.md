# 卡密管理

卡密用于按设备或 IP 授权终端客户端。卡密属于某个应用，可单个创建，也可按批次批量生成。

## 主要字段

| 字段 | 说明 |
| --- | --- |
| 卡密类型 | 业务侧定义的授权类型 |
| 时长 | 生效时长及单位，可支持永久 |
| 使用次数 | 卡密允许的登录或使用次数 |
| 解绑次数 | 允许自助或接口解绑的次数 |
| 设备校验 | 是否要求设备标识一致 |
| IP 校验 | 是否要求来源 IP 一致 |
| 使用时段 | 限制允许使用的时间范围 |
| 到期时间 | 激活或加时后计算出的到期时间 |

## 常用操作

- 创建单个卡密或批量生成卡密。
- 启用、停用、删除卡密。
- 批量加时、设置使用次数、设置解绑次数和使用时段。
- 查看并解绑设备、IP，管理员解绑不会触发应用配置的换绑扣时。
- 查看首次使用、最后使用、使用次数、绑定用户和心跳时间。

## 自助解绑

[卡密自助服务](/self-service/license) 允许用户按应用查询卡密状态，并按剩余次数解绑设备或 IP。解绑次数耗尽后需要管理员处理。

## 与第三方登录的关系

客户端通过 `/api/v1/card/login` 使用卡密和设备标识登录。首次登录会激活并绑定卡密；换绑接口可能按应用配置扣减有效期。接口细节见 [API 对接](/developer/api-integration)。


## 不接入心跳也能统计登录

只调用卡密登录接口的客户端，不需要为了统计而接入心跳：成功登录会记录卡密身份及设备摘要，在首页「登录与访客统计」查看去重活跃卡密、活跃设备和近期登录流水。

免费模式不创建真实卡密，使用应用隔离的访客统计身份。没有心跳时，登录数据表示访问或活跃，而不是连续在线时长。具体指标见 [开发者中心](/developer/)。
