# 公开入口与认证安全

## 接入变更

本次更新同时提供前端页面和后端校验，部署时应一起更新。第三方签名接口 `/api/v1/**` 的报文、充值签名和卡密兑换规则不变。以下公开自助入口不再支持仅邮箱查询；自建调用方需同步调整。

| 操作 | 额外校验 | 图形验证码用途 |
| --- | --- | --- |
| 注册发送邮件 | 一次性图形验证码，IP/邮箱/全站发信预算 | `register-email` |
| 查询卡密 | 卡密 + 一次性图形验证码 | `license-query` |
| 解绑卡密 | 卡密 + 独立的一次性图形验证码，仍需业务解绑额度 | `license-unbind` |
| 用户会员查询 | 注册邮箱 + 该应用账号密码 + 一次性图形验证码 | `app-user-query` |
| 开放试用申请 | 邮箱 + 该应用账号密码 + 一次性图形验证码 | `trial-apply` |
| 开放试用到期查询 | 邮箱 + 该应用账号密码 + 一次性图形验证码 | `trial-query` |

先调用 `GET /api/public/challenge?purpose=对应用途`，从响应 `data` 取得 `captchaId` 和 `image`。图片只供人阅读，答案不会通过响应返回。业务请求体增加 `captchaId`、`captchaCode`；试用及用户查询同时增加 `password`。验证码3分钟有效、绑定规范化来源IP、仅可尝试一次；答错、换用途、重放都需要重新获取。每个入口还按IP及账号/卡密摘要限制请求，超过限额返回429。

公开试用返回仅保留应用ID、试用天数（申请时）和到期时间，不再返回用户ID和完整邮箱。账号不存在与密码不匹配统一提示“邮箱或密码错误”。

## 邮箱与密码

- 注册邮箱验证码3分钟有效，最多5次尝试，成功校验原子消费；同一应用同邮箱60秒发送窗口原子领取。数据库写入失败后需重新获取验证码，不会复用已经消费的码。
- 找回密码先完成图形验证，再发送邮件；填写邮箱验证码验证所有权后，才能取得关联应用列表。见[密码找回](/portal/password-recovery)。
- 换邮箱发信仅允许正式门户会话，验证码绑定用户、应用、用途及目标邮箱；不能匿名调用或使用选应用票据。
- 找回及换邮箱验证码5分钟有效，每码最多8次校验；SQL行锁与事务保证仅消费一次，用户更新失败会回滚消费。Redis尝试次数不会随SQL回滚而恢复。
- 新密码服务端统一要求6～50个字符，UTF-8编码不超过72字节。旧密码登录不强制新的最短长度；超出BCrypt字节上限的历史密码应走找回流程重新设置。
- 日志不记录验证码、完整卡密、密码及其哈希；终端用户实体的密码字段只允许写入，不序列化到浏览器。

## 多应用门户会话

同邮箱不代表同一应用身份。登录会分别校验各应用账号密码，仅返回本次确实验密成功且启用的应用。多应用选择票据最长5分钟，只允许选择授权集合中的应用，不能访问资料、订单、支付或设置接口。

正式会话逐请求核对用户/应用存在与启用状态、凭据指纹。改密、换邮箱、删除账号及禁用应用后，旧会话失效。本次引入用途与凭据绑定，升级前的门户JWT也需重新登录；平台后台会话不受此变更影响。

## 可信来源地址

业务代码仅读取 `request.getRemoteAddr()`。Spring Boot原生RemoteIpValve负责可信代理头的规范化；外部客户端自带的 `X-Forwarded-For` 不由业务代码直接采信。入口Nginx/CDN/WAF需按真实网络拓扑配置可信代理，并覆盖向后端传递的地址。不要把全网地址加入可信代理列表。此项代码修复不会替运维修改线上防火墙或代理配置。

## 运维与验证

Redis用于共享计数、一次性挑战和发送冷却，失联时拒绝受保护操作，不静默关闭防护。找回邮件采用有界异步队列，SMTP耗时不参与账号存在性响应；队列不是持久任务系统，重启前尚未发送的请求可在冷却结束后重试。

文档附件上传使用受限磁盘暂存、创建人权限校验及服务端生成的对象键；重启后需重新上传。详见[内容管理](/admin/content)。数据库迁移只新增V3，恢复需隔离空库，详见[安装、更新与恢复](/operations)。完整运行时依赖扫描见[依赖安全门禁](/developer/dependency-security)。

CI覆盖跨应用登录、临时票据权限、OTP并发消费/回滚、真实Redis限流/重放、上传并发/字节上限、桌面与移动交互及恢复演练。运行测试不等于已验证线上代理信任链；上线仍需单独批准和备份。
