# 管理后台

管理后台面向系统管理员。功能分布在 `/system/`、`/admin/` 和开发者应用配置中，菜单由角色和权限控制。

## 管理范围

| 页面 | 路由 | 说明 |
| --- | --- | --- |
| 用户管理 | `/system/users` | 平台账号、状态、角色和密码重置 |
| 角色管理 | `/system/roles` | 角色、菜单权限和 API 权限 |
| 菜单管理 | `/system/menus` | 后台导航树、路由和可见性 |
| 权限管理 | `/system/permissions` | HTTP 方法和资源路径权限 |
| 系统信息 | `/system/info` | 应用、系统、Java、内存和技术栈状态 |
| 系统配置 | `/system/config` | 登录、站点、邮件、支付、IP 库、代理和邀请 |
| 公告 | `/system/announcements` | 平台公告 |
| 会员与配额 | `/membership/levels` 等 | 等级、用户会员和额度商品 |
| 插件 | `/plugins`、`/function-plugins` | 插件上传、启停、配置和应用授权 |
| 订单与工单 | `/admin/orders`、`/admin/tickets` | 手动发放、工单处理和沟通 |
| 文档管理 | `/admin/docs/categories` | 分类、文档、附件和查看 |

## 权限排查

| 现象 | 检查项 |
| --- | --- |
| `401 未登录` | 重新登录，确认会话有效 |
| `403 权限不足` | 当前用户角色、对应 API 权限及接口的额外角色要求 |
| 页面可见但不能保存 | 保存接口的 HTTP 方法、资源路径和授权 |
| 用户无法看到入口 | 角色菜单授权、菜单状态与可见性 |

菜单权限控制入口，API 权限控制后端操作。涉及重置平台密码等操作，还需满足接口的超级管理员角色校验。

## 变更原则

- 先在测试环境验证支付、邮件、代理和插件配置。
- 修改 AppSecret、API Secret、支付密钥或代理密码时记录变更时间。
- 插件上传前校验来源和 SHA-256。
- 手动发放订单前确认支付凭证，避免重复发放。
