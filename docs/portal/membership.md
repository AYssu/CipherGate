# 会员信息

会员信息页面展示您的会员状态和详细信息。

## 会员信息

- **会员状态**：未开通/有效/已过期
- **会员等级**：当前会员等级
- **到期时间**：会员到期时间
- **剩余天数**：距到期的剩余天数

## 会员权益

| 权益 | 说明 |
|------|------|
| 基础功能 | 使用应用基础功能 |
| 高级功能 | 使用应用高级功能 |
| 优先支持 | 享受优先技术支持 |
| 专属客服 | VIP 用户专属客服 |

## 延长会员

### 方式 1：卡密激活

1. 获取卡密
2. 前往 [卡密激活](/self-service/license) 页面
3. 输入卡密并激活

### 方式 2：在线充值

1. 前往 [充值](/portal/recharge) 页面
2. 选择充值套餐
3. 完成支付

## 常见问题

### Q: 会员到期后数据会丢失吗？
A: 数据会保留 30 天，到期后请及时续费。

### Q: 如何升级会员等级？
A: 联系应用管理员申请升级。
