# Portal 充值

充值页展示当前应用开放的配额产品。产品名称、价格、时长和额度由应用或管理员配置，不使用固定套餐。

## 充值流程

1. 选择产品和数量。
2. 创建支付订单。
3. 跳转到支付页面完成支付。
4. 返回应用，通过订单页和会员页确认结果。

支付功能受应用的 Portal 支付开关、支付系统配置和产品状态共同影响。如果页面没有产品或无法下单，通常是应用未开启支付或没有可用产品。

## 支付结果

- 订单已支付、会员已更新：流程完成。
- 订单已支付、会员未更新：等待回调或提交订单号给管理员。
- 订单待支付：完成支付或等待订单关闭。

Portal 当前提供支付和订单记录，不提供在线退款申请或发票下载。
