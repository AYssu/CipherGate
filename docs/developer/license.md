# 卡密管理

卡密（License Key）是用于激活用户会员资格的唯一标识符。

## 功能列表

| 功能 | 说明 |
|------|------|
| 生成卡密 | 批量生成卡密 |
| 导入卡密 | 从文件导入卡密 |
| 导出卡密 | 导出卡密到文件 |
| 查询卡密 | 搜索和筛选卡密 |
| 查看详情 | 查看卡密使用情况 |
| 删除卡密 | 删除未使用的卡密 |

## 生成卡密

### 步骤 1：进入卡密管理

1. 登录开发者后台
2. 点击左侧菜单「应用管理」→「卡密管理」

### 步骤 2：点击生成

1. 点击页面右上角「生成卡密」按钮
2. 填写生成配置

### 步骤 3：配置参数

| 参数 | 说明 | 必填 |
|------|------|------|
| 数量 | 生成卡密的数量 | ✅ |
| 会员等级 | 卡密对应的会员等级 | ✅ |
| 有效期 | 卡密的有效期 | ✅ |
| 备注 | 卡密的备注信息 | ❌ |

### 步骤 4：确认生成

1. 点击「确定」按钮
2. 系统自动生成卡密
3. 可选择下载或复制卡密

## 卡密状态

| 状态 | 说明 |
|------|------|
| 未使用 | 卡密未被激活 |
| 已使用 | 卡密已被用户激活 |
| 已过期 | 卡密已过期 |
| 已禁用 | 卡密被手动禁用 |

## 卡密筛选

支持按以下条件筛选卡密：

- 状态：未使用、已使用、已过期
- 会员等级
- 生成时间
- 使用时间
- 备注关键词

## 卡密详情

点击卡密可查看详情：

- 卡密号
- 状态
- 会员等级
- 有效期
- 使用用户（已使用时显示）
- 使用时间
- 备注

## 最佳实践

::: tip 建议
- 批量生成卡密时，建议添加备注便于管理
- 定期导出卡密备份
- 监控卡密使用情况，及时补充
:::

::: warning 注意
- 已使用的卡密无法删除
- 删除卡密前请确认卡密未分发
:::
