# 卡密自助查询与解绑

卡密自助页面路由为 `/license?id=应用ID`。应用方应把专属链接提供给用户，缺少或错误的 `id` 时页面无法查询。

## 查询卡密

输入完整卡密后，页面显示：

- 脱敏卡密。
- 状态：未使用、使用中、已到期或已禁用。
- 到期时间和剩余时长。
- 是否绑定设备或 IP。
- 已解绑次数、解绑上限和剩余次数。

## 自助解绑

点击解绑后会同时解除当前卡密的设备和 IP 绑定。解绑成功后可在新设备或新 IP 下重新登录绑定。

解绑受卡密剩余次数限制。剩余次数为 -1 表示不限制；次数耗尽后联系应用管理员。应用管理员在后台解绑不会消耗该自助次数。
