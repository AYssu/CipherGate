# 第三方凭证

第三方凭证用于配置外部服务的访问凭证，如支付网关、邮件服务等。

## 功能列表

| 功能 | 说明 |
|------|------|
| 添加凭证 | 添加第三方服务凭证 |
| 编辑凭证 | 修改凭证信息 |
| 删除凭证 | 删除凭证 |
| 测试连接 | 测试凭证是否有效 |

## 支持的服务

| 服务类型 | 说明 |
|------|------|
| 支付服务 | 微信支付、支付宝等 |
| 邮件服务 | SMTP 配置 |
| 短信服务 | 短信网关配置 |
| 存储服务 | 对象存储配置 |
| 自定义 | 其他第三方服务 |

## 添加凭证

### 步骤 1：进入凭证管理

1. 登录开发者后台
2. 点击左侧菜单「应用管理」→「第三方凭证」

### 步骤 2：点击添加

1. 点击「添加凭证」按钮
2. 选择服务类型

### 步骤 3：填写信息

| 字段 | 说明 | 必填 |
|------|------|------|
| 凭证名称 | 凭证的显示名称 | ✅ |
| 服务类型 | 选择服务类型 | ✅ |
| API Key | 服务的 API Key | ✅ |
| API Secret | 服务的 API Secret | ✅ |
| 其他参数 | 服务特定的配置 | ❌ |

### 步骤 4：测试和保存

1. 点击「测试连接」验证凭证
2. 测试通过后点击「保存」

## 安全提示

::: warning 注意
- 凭证信息会加密存储
- 不要分享您的 API Key 和 Secret
- 定期轮换凭证
:::
