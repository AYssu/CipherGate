# 开发者中心

欢迎使用 CipherGate 开发者中心！这里是应用创建者和管理者的控制台。

## 功能概览

登录开发者后台后，您可以在左侧菜单中找到以下功能模块：

### 📊 仪表盘
- 应用数据概览
- 用户统计信息
- 最近活动记录

### 📱 应用管理
- [应用列表](/developer/application) - 创建和管理应用
- [卡密管理](/developer/license) - 卡密生成和分发
- [终端用户管理](/developer/app-user) - 管理应用用户
- [变量管理](/developer/variable) - 自定义配置
- [第三方凭证](/developer/credential) - 外部服务配置
- [调用日志](/developer/call-log) - API 调用记录

### 👤 用户中心
- [会员信息](/user/membership) - 查看会员状态
- [余额管理](/user/balance) - 账户余额
- [签到](/user/checkin) - 每日签到奖励
- [邀请](/user/invite) - 邀请好友
- [订单](/user/order) - 购买记录
- [工单](/user/ticket) - 提交工单

### 🔌 插件管理
- 安装和管理扩展插件

### 📚 文档管理
- 查看使用文档

## 快速上手

1. **创建应用** → [应用管理](/developer/application)
2. **配置卡密** → [卡密管理](/developer/license)
3. **邀请用户** → [终端用户管理](/developer/app-user)
4. **查看数据** → [仪表盘](/developer/)
