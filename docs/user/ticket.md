# 工单

工单页用于向平台管理员反馈技术、账单、功能建议和其他问题。

## 创建工单

填写标题、分类、优先级和问题描述。提交后获得唯一工单号，后续沟通都在该工单中进行。

## 工单状态

| 状态 | 说明 |
| --- | --- |
| 待处理 | 已提交，等待管理员接单 |
| 处理中 | 管理员正在处理 |
| 等待回复 | 需要用户补充信息 |
| 已解决 | 问题已完成处理 |
| 已关闭 | 工单关闭，不再接受回复 |

## 回复、催办与关闭

- 在详情中补充文字回复。
- 待处理或处理中的工单可以催办。
- 用户可以在问题解决后关闭工单。

涉及支付、权限或第三方接口时，请附上订单号、用户 ID、应用 ID、时间和 traceId，避免只提供截图。
