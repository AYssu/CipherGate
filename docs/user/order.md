# 订单

订单页展示当前平台用户的商品、配额和充值订单。

## 订单字段

| 字段 | 说明 |
| --- | --- |
| 订单号 | 唯一查询标识 |
| 商品 | 购买的商品或套餐 |
| 金额 | 实际订单金额 |
| 状态 | 待支付、已支付或失败等状态 |
| 支付方式 | 实际支付渠道 |
| 创建时间 | 下单时间 |

页面只展示订单和支付状态，不提供发票下载或自动退款申请。支付异常、重复支付和退款需求请通过工单提交订单号。

## 支付后检查

1. 刷新订单页查看状态。
2. 查看余额流水或会员额度是否到账。
3. 订单长期停留在待支付时，检查支付渠道回调或提交工单。
