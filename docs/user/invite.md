# 邀请

**入口：** `/user/invite` · **适用对象：** 平台账号

邀请页展示个人邀请码、邀请人数、奖励统计和邀请记录。

## 使用方式

1. 复制个人邀请码或邀请链接，分享给其他平台用户。
2. 对方通过平台账号流程登录，并按页面提示绑定邀请码。
3. 绑定成功后，邀请记录更新，奖励进入邀请人的平台余额。

邀请功能开关、奖励金额和邀请人数上限由管理员设置。此处不为应用终端用户建立邀请关系。

## 绑定规则

- 每个账号只能绑定一次邀请人，不能重复绑定或更换。
- 不能绑定自己的邀请码。
- 邀请码必须有效，且邀请人未达到人数上限。
- 邀请功能关闭时无法绑定。

## 核对奖励

在本页查看邀请记录，在 [余额管理](/user/balance) 核对余额奖励。记录与余额不一致时，请提供邀请双方的平台用户 ID 和操作时间，由管理员检查。
