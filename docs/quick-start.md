# 快速开始

CipherGate 当前提供开发者后台、普通用户中心、应用用户 Portal 和系统管理后台。不同入口使用不同的账号和权限，请先确认自己的身份。

## 选择入口

| 身份 | 入口 | 主要任务 |
| --- | --- | --- |
| 应用开发者/运营者 | `/login` 后进入 `/dashboard` | 创建应用、卡密、终端用户，配置插件和第三方接口 |
| 普通平台用户 | `/user/` | 查看会员、余额、签到、邀请、订单和工单 |
| 应用终端用户 | `/portal/` | 登录应用、查看控制台、充值、订单和账号设置 |
| 系统管理员 | `/system/`、`/admin/` | 管理权限、系统配置、会员配额、插件和内容 |

## 最短路径

1. 使用管理员创建或启用账号。
2. 登录开发者后台，在「应用管理」创建应用并保存 AppKey/AppSecret。
3. 在「卡密管理」或「终端用户管理」准备授权数据。
4. 在「第三方凭证」「变量管理」「插件管理」中完成客户端接入配置。
5. 使用 [第三方 API 对接](/developer/api-integration) 按签名和加密规则联调。
