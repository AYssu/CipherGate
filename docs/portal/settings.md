# 设置

设置页面用于管理个人信息和账号安全。

## 功能列表

| 功能 | 说明 |
|------|------|
| 个人信息 | 修改昵称、头像等 |
| 密码修改 | 修改登录密码 |
| 绑定设备 | 查看和管理绑定设备 |

## 个人信息

### 修改头像

1. 点击头像区域
2. 上传新头像
3. 裁剪并保存

### 修改昵称

1. 点击昵称输入框
2. 输入新昵称
3. 点击保存

## 密码修改

### 修改步骤

1. 输入当前密码
2. 输入新密码
3. 确认新密码
4. 点击「保存」

::: warning 注意
- 新密码至少 8 位
- 需包含字母和数字
- 修改后需要重新登录
:::

## 绑定设备

### 查看绑定设备

- 设备名称
- 设备类型
- 绑定时间
- 最后活跃时间

### 解绑设备

1. 在设备列表找到目标设备
2. 点击「解绑」按钮
3. 确认解绑操作

::: warning 注意
- 解绑后该设备将无法使用
- 如设备丢失请及时解绑
:::
