# 用户中心

用户中心面向平台普通用户，入口为 `/user/`。该区域与应用终端用户的 Portal 分开，数据和权限不互通。

## 功能入口

| 页面 | 路由 | 说明 |
| --- | --- | --- |
| 会员信息 | `/user/membership` | 等级、额度、有效期和会员记录 |
| 余额管理 | `/user/balance` | 余额、交易记录、充值和配额产品购买 |
| 签到 | `/user/checkin` | 每日签到及卡密、用户、流量额度奖励 |
| 邀请 | `/user/invite` | 邀请码、邀请统计和奖励记录 |
| 订单 | `/user/orders` | 平台商品和充值订单 |
| 工单 | `/user/tickets` | 创建、回复、催办和关闭工单 |

## 仪表盘与消息

登录后的仪表盘会展示应用、终端用户、卡密、在线数量和趋势，并汇总系统消息与最近活动。消息和活动支持单条已读或一键全部已读。

## 个人资料

`/profile` 展示账号身份和统计数据。已通过第三方账号登录的用户可以设置平台密码；修改后请使用新密码重新登录。
