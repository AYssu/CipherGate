# 插件管理

插件分为通用 PF4J 插件和函数插件。插件包上传到对象存储，并记录 SHA-256。

## 通用插件

通用插件支持：

- 上传、启用、停用和删除。
- 查看插件 ID、版本、状态和 SHA-256。
- 按插件 Schema 编辑配置。

应用加密依赖加密插件。切换应用加密插件时必须同步更新加密配置，否则请求可能返回 `DECRYPT_EMPTY` 或解密失败。

## 函数插件

函数插件额外支持：

- 查看插件暴露的函数和示例。
- 使用 JSON 参数测试函数。
- 按应用查看或替换插件授权。

函数插件应用授权采用白名单。只有被授权的应用可以使用相应函数，更新授权会替换旧列表。

## 发布检查

1. 校验插件包来源和 SHA-256。
2. 上传后先停用状态下检查版本和 Schema。
3. 在测试环境启用并验证配置。
4. 使用函数测试控制台验证输入输出。
5. 最小范围分配应用授权。

加载失败时先检查插件版本、依赖、`Plugin-Class` 清单和后端日志，再决定重新上传或停用。
