# 会员信息

会员信息页面展示您的会员状态和详细信息。

## 会员状态

| 状态 | 说明 |
|------|------|
| 未开通 | 尚未开通会员 |
| 会员有效 | 会员在有效期内 |
| 已过期 | 会员已过期 |

## 会员信息

- **会员等级**：当前会员等级
- **到期时间**：会员到期时间
- **开通时间**：会员开通时间
- **剩余天数**：距到期的剩余天数

## 会员权益

不同等级的会员享有不同的权益：

| 等级 | 权益 |
|------|------|
| 普通会员 | 基础功能 |
| 高级会员 | 高级功能 + 优先支持 |
| VIP 会员 | 全部功能 + 专属客服 |

## 常见问题

### Q: 如何延长会员？
A: 可以通过卡密激活或在线充值延长会员。

### Q: 会员到期后会怎样？
A: 到期后将无法使用付费功能，数据会保留 30 天。

### Q: 如何升级会员等级？
A: 联系管理员或通过购买升级。
