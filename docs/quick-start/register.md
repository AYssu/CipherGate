# 账号注册

当前开放的注册入口主要是应用终端用户注册。开发者账号和管理员账号由管理员创建或通过现有账号体系授权，不依赖公开自助注册。

## 应用用户注册

1. 通过应用管理员提供的 `/register?id=应用ID` 链接进入注册页。
2. 填写用户名、邮箱、邮箱验证码和密码。
3. 提交后使用同一账号登录 Portal。

邮箱验证码、密码长度和用户名规则由服务端校验；验证码发送失败时先检查邮箱地址和邮件垃圾箱。

## 开发者账号

开发者账号由管理员在用户管理中创建，并通过角色、菜单和 API 权限授予后台功能。若没有账号，请联系管理员，不要使用终端用户注册页申请后台权限。

## 注册后检查

- 能否登录并进入对应入口。
- 应用用户能否选择正确的应用。
- 开发者是否能看到应用管理菜单。
- 管理员是否已授予必要的角色和权限。
