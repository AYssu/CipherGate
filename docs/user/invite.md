# 邀请

邀请好友注册可以获得奖励。

## 邀请规则

| 规则 | 说明 |
|------|------|
| 邀请码 | 每个用户有专属邀请码 |
| 邀请链接 | 可分享邀请链接 |
| 奖励条件 | 被邀请人注册并激活 |

## 邀请奖励

| 奖励类型 | 说明 |
|----------|------|
| 余额奖励 | 获得一定余额 |
| 会员时长 | 获得额外会员天数 |
| 积分奖励 | 获得积分 |

## 邀请流程

1. 复制您的邀请码或邀请链接
2. 分享给好友
3. 好友使用邀请码注册
4. 好友激活会员后获得奖励

## 邀请统计

- 邀请总人数
- 成功邀请人数
- 获得奖励总额

## 最佳实践

::: tip 建议
- 分享邀请链接到社交平台
- 邀请更多好友获得更大奖励
- 查看邀请统计了解效果
:::
