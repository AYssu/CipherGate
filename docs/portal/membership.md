# Portal 会员信息

**入口：** `/portal/membership` · **适用对象：** 已登录的应用终端用户

该页面展示当前应用的会员与试用状态。同一邮箱在其他应用中的会员数据单独维护。

## 页面信息

| 信息 | 说明 |
| --- | --- |
| 会员状态 | 会员有效、已到期、试用期或未开通 |
| 到期时间 | 会员到期时间；试用状态下展示试用到期时间 |
| 登录次数与最近登录 | 当前应用用户的登录记录摘要 |
| 试用信息 | 已有试用记录时，展示试用状态与到期时间 |

这里的会员与平台 [用户中心会员](/user/membership) 不同，不展示平台的应用、卡密和流量配额。

## 充值与核对

选择「充值续费」前往 [Portal 充值](/portal/recharge)。支付后通过订单记录和本页核对结果；应用管理员操作、卡密激活及第三方充值也可能改变会员到期时间。

支付成功但会员未更新时，请将订单号、支付时间和当前应用 ID 提供给应用方，核对支付回调与发放结果。
