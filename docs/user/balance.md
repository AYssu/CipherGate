# 余额管理

余额管理用于查看和管理您的账户余额。

## 功能列表

| 功能 | 说明 |
|------|------|
| 查看余额 | 查看当前账户余额 |
| 充值 | 在线充值余额 |
| 充值记录 | 查看充值历史 |
| 消费记录 | 查看消费明细 |

## 余额说明

- **可用余额**：当前可使用的余额
- **冻结余额**：暂不可用的余额
- **累计充值**：历史充值总额
- **累计消费**：历史消费总额

## 充值方式

| 方式 | 说明 |
|------|------|
| 在线支付 | 支持微信、支付宝 |
| 卡密充值 | 使用卡密兑换余额 |
| 后台充值 | 管理员手动充值 |

## 账单明细

支持按时间范围筛选：

- 充值记录
- 消费记录
- 退款记录

## 最佳实践

::: tip 建议
- 定期查看账单明细
- 保留充值凭证
- 设置余额提醒
:::
