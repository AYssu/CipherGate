# 工单

工单系统用于提交技术支持请求和问题反馈。

## 功能列表

| 功能 | 说明 |
|------|------|
| 创建工单 | 提交新的技术支持请求 |
| 查看工单 | 查看工单列表和详情 |
| 回复工单 | 补充工单信息 |
| 关闭工单 | 关闭已解决的工单 |

## 工单类型

| 类型 | 说明 |
|------|------|
| 技术问题 | 功能使用问题 |
| 账号问题 | 账号相关问题 |
| 功能建议 | 新功能建议 |
| 其他 | 其他问题 |

## 创建工单

### 步骤 1：进入工单页面

1. 登录用户中心
2. 点击左侧菜单「工单」

### 步骤 2：点击创建

1. 点击「创建工单」按钮
2. 填写工单信息

### 步骤 3：填写信息

| 字段 | 说明 | 必填 |
|------|------|------|
| 工单标题 | 简短描述问题 | ✅ |
| 工单类型 | 选择问题类型 | ✅ |
| 问题描述 | 详细描述问题 | ✅ |
| 附件 | 相关截图或文件 | ❌ |

### 步骤 4：提交工单

1. 点击「提交」按钮
2. 等待客服回复

## 工单状态

| 状态 | 说明 |
|------|------|
| 待处理 | 等待客服处理 |
| 处理中 | 客服正在处理 |
| 已回复 | 客服已回复 |
| 已关闭 | 工单已关闭 |

## 最佳实践

::: tip 建议
- 详细描述问题，附上截图
- 及时回复客服的消息
- 问题解决后及时关闭工单
:::
