# 账号注册

CipherGate 有平台账号与应用终端用户两套身份。请先确认使用场景，再选择入口。

| 使用场景 | 账号来源 | 后续入口 |
| --- | --- | --- |
| 使用平台、管理应用 | 首页 GitHub 授权登录 | `/dashboard` |
| 使用某个应用 | 应用方提供的专属注册链接 | `/portal/login` |

## 创建平台账号

1. 打开平台首页，选择 GitHub 登录并完成授权。
2. 首次授权时，平台创建对应账号；后续登录沿用已有账号。
3. 需要密码登录时，先登录平台，在个人资料中设置平台密码。
4. 应用管理或系统管理权限由角色决定，需要时联系管理员授权。

首次部署需先完成 GitHub OAuth 初始化。部署人员请参阅 [部署与运维](/operations)。

## 注册应用用户

1. 打开应用方提供的 `/register?id=应用ID` 链接。
2. 填写用户名、邮箱，完成图形验证后发送邮箱验证码；填写邮箱验证码、密码和确认密码，提交注册。注册成功后，页面显示回执，可选择“前往登录”。
3. 打开 `/portal/login`，使用注册邮箱和密码登录。
4. 如果邮箱关联多个应用，按页面提示选择应用。

注册只创建指定应用内的终端用户，不会授予平台后台权限。邮箱验证码依赖管理员配置的邮件服务；发送失败时先核对邮箱和垃圾邮件，再联系应用方。

## 完成检查

- 平台账号：能进入仪表盘，并看到已授权的功能菜单。
- 应用用户：能进入目标应用的 Portal，会员和订单归属正确。

应用终端用户通过 `/register?id=应用ID` 注册时，密码为 6～50 位，UTF-8 编码不超过 72 字节，不能全为空白。中文和表情可能占用多个字节；页面会在提交前校验。注册、改密使用同一后端密码策略。
