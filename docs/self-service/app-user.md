# 用户会员查询与卡密充值

用户自助页面路由为 `/app-user?id=应用ID`，提供应用终端用户的会员到期查询和卡密充值。

## 查询会员

1. 通过应用方提供的专属链接进入。
2. 在查询区域输入注册邮箱、该应用的账号密码和图形验证码，点击「查询」。验证码每次操作后都需刷新，账号不存在与密码不匹配统一提示。
3. 查看脱敏邮箱、会员状态、到期时间和剩余时长。

## 使用卡密充值

1. 在「卡密充值」区域填写本应用的注册邮箱和未使用时长卡。
2. 点击「兑换充值」，核对确认框中的目标邮箱。
3. 确认后等待到账结果，页面同步展示新的会员到期时间。

会员尚未到期时，在原到期时间后累加卡密时长；已到期或未开通时，从当前时间开始计算。月卡、季卡和年卡按日历月、年计算，不统一换算为固定天数。卡密必须与目标用户属于同一应用。

充值会完整消耗一张卡密；不支持拆分、转移或自助撤销。已激活、已兑换、已禁用、已删除或已绑定的卡密不可兑换，已兑换卡密不能再用于 HTTP 或 WebSocket 卡密登录。重置卡密状态不会使其恢复可用。

支持天、周、月、季、半年、年及明确设置正数时长和单位的自定义卡。永久卡、指定固定到期时间的卡、限定每日使用时段的卡暂不支持兑换。业务校验失败时不会增加会员时长或消耗卡密，可按提示核对后重试。网络超时或中断时，服务端可能已完成兑换，应先查询会员状态；重复提交同一卡密不会重复加时。

卡密是持有者凭证，不需要管理员登录即可为指定邮箱充值；请通过 HTTPS 使用，不要将卡密放入链接、截图或公开日志。务必核对充值邮箱。

## 信息边界

页面仅展示有限的会员信息，不提供完整账号、设备绑定、登录记录、订单、管理员解绑或封禁操作。改密使用 [Portal 密码找回](/portal/password-recovery)。
