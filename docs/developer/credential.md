# 第三方凭证

第三方凭证用于授权外部服务调用充值等第三方接口。每条凭证包含独立的 `apiKey` 和 `apiSecret`。

## 创建与轮换

创建凭证时可配置名称、允许 IP、日调用上限、总调用上限、总天数上限、过期时间和备注。系统生成 API Key/Secret。

API Secret 支持轮换。轮换后旧 Secret 失效，调用方必须更新签名密钥。

## 限制项

| 限制 | 说明 |
| --- | --- |
| 允许 IP | 支持按配置限制来源 IP |
| 日调用上限 | 每个自然日允许的调用次数 |
| 总调用上限 | 凭证生命周期内允许的总次数 |
| 总天数上限 | 凭证允许使用的总天数 |
| 过期时间 | 到期后凭证不可用 |
| 状态 | 启用或停用 |

## 调用记录

凭证相关请求会记录到 [调用日志](/developer/call-log)，包含请求 IP、签名结果、幂等命中、错误码、变更前后到期时间和 traceId。

::: warning
API Secret 是长期凭证，只能保存在服务端安全配置中。不要写入前端代码、公开仓库或客户端安装包。
:::
