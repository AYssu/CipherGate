# 开发者中心

开发者中心用于维护应用及其授权数据。登录后从 `/dashboard` 进入，核心菜单包括：

| 菜单 | 路由 | 用途 |
| --- | --- | --- |
| 应用管理 | `/applications/list` | 应用基础信息、密钥、版本、加密、代理和门户支付配置 |
| 卡密管理 | `/applications/licenses` | 单个或批量生成、激活、绑定、加时和解绑 |
| 终端用户管理 | `/applications/users` | 账号用户、会员到期、设备绑定、在线状态和封禁 |
| 用户迁移 | `/applications/user-transfer` | 预检查并确认跨应用复制、迁移及冲突处理 |
| 变量管理 | `/applications/variables` | 应用变量、安全等级、版本、历史、导入导出 |
| 第三方凭证 | `/applications/credentials` | API Key/Secret、IP 白名单、调用限额和有效期 |
| 调用日志 | `/applications/call-logs` | 第三方充值请求、签名校验、幂等和错误记录 |

## 推荐配置顺序

1. 创建应用并保存生成的 AppKey/AppSecret。
2. 选择加密插件，按插件模板填写加密配置。
3. 配置版本号、公告、更新包和换绑策略。
4. 创建卡密或终端用户。
5. 需要外部充值时，创建第三方凭证并选择完整授权应用集合，设置 IP、调用限额和有效期。
6. 使用 [API 对接文档](/developer/api-integration) 完成签名、加密和联调。

## 权限说明

开发者只能查看其有权访问的应用数据。应用代理可被限制为只能管理自己创建的数据，或查看应用全部数据；具体可见 [应用管理](/developer/application)。

## 登录与访客统计

首页「登录与访客统计」记录客户端访问。客户端只调用 `/api/v1/card/login` 或账号接口 `/api/v1/user/login` 并成功登录，就会记录一次访问；不要求接入心跳，也不需要把免费应用改成账号或付费卡密模式。

| 指标 | 统计口径 |
| --- | --- |
| 今日 HTTP 用户登录 / 今日及 7 日活跃用户 | 成功账号登录次数，以及按应用和用户 ID 去重的用户数，计入综合在线的 HTTP 5 分钟窗口，不计入 WS 会话或时长 |
| 今日卡密登录 / 免费登录 | 成功登录次数，同一设备重复登录按次累计 |
| 今日 / 7 日活跃卡密 | 窗口内成功登录的不同卡密，复用真实卡密 ID |
| 今日 / 7 日免费访客 | 按应用及登录上报的设备标识去重，不创建虚拟账号、卡密 |
| 今日 / 7 日活跃设备 | 设备标识按应用隔离去重；同一应用内卡密、账号和免费登录使用同一个设备摘要 |
| 最近 5 分钟登录 | 最近 5 分钟内成功登录的不同卡密、免费访客和 HTTP 用户，不是实时在线 |
| 近 7 天成功登录记录 | 分页展示应用、统计身份、设备摘要、来源 IP 和登录时间；不展示卡密明文或心跳 token |

统计仅覆盖当前登录用户作为 owner 的应用。日期按后端服务器时区划分；7 日包含今日及前 6 个自然日。设备数是客户端设备标识的去重结果，不等于真实人数，清除或改变设备标识会影响统计。

::: warning 在线与活跃不要混淆
未发送心跳的客户端，在登录后是否仍在使用无法可靠判断，因此不计算它的连续在线时长。原有卡密活跃指标按最近 5 分钟使用记录计算，首页现标记为「近期活跃卡密」；终端用户综合在线包含真实 WS 会话和最近 5 分钟 HTTP 成功登录，后者不计入 WS 会话数或在线时长。
:::

旧客户端不用修改请求或处理新增响应字段。历史卡密登录能按卡密 ID 去重；历史免费登录未记录设备，只保留次数，不补算独立访客。设备摘要是统计关联标识，不是登录凭证，也不授予付费或后台权限。

## 操作指南

- [应用管理](/developer/application)：配置应用、上传更新包及后台下载。
- [第三方 API 对接](/developer/api-integration)：应用签名、加密、账号登录和临时更新下载。
- [第三方凭证](/developer/credential)：多应用充值授权及独立充值签名。
- [用户迁移与复制](/developer/user-transfer)：范围确认、预检查、冲突处理和结果核验。

- [公开入口与认证安全](/developer/public-security)：验证码、密码校验、多应用会话与接口变更。
- [运行时依赖安全](/developer/dependency-security)：完整扫描、补丁版本与维护门禁。
