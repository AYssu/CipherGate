# Portal 订单记录

订单记录展示当前应用下的充值订单。

## 订单字段

- 订单号。
- 商品名称。
- 订单金额。
- 订单状态。
- 创建时间。
- 支付时间。

订单按应用隔离，切换应用后不会显示其他应用的订单。需要核对支付时，请提供完整订单号、商品名称、金额和支付时间。

## 刷新与翻页

每页最多展示 20 条订单，通过「上一页」「下一页」查看历史。接口不提供总条数，因此页面不显示推算的总页数；上一页恰好满 20 条时，下一页可能为空。

加载失败时显示明确的错误和「重新加载」。已有列表会保留，并标注为上次加载结果；刷新成功前不要把旧状态当作最新支付结果。

从支付渠道返回仅表示打开了订单页面，不能证明已支付。以列表中的服务端订单状态和会员到账记录为准；待支付状态可稍后点击「刷新订单」复核。
