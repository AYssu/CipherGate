# 订单

订单页面展示您的所有购买记录。

## 订单字段

| 字段 | 说明 |
|------|------|
| 订单号 | 唯一订单标识 |
| 商品名称 | 购买的商品 |
| 订单金额 | 支付金额 |
| 支付状态 | 已支付/待支付/已退款 |
| 支付方式 | 微信/支付宝/余额 |
| 创建时间 | 下单时间 |
| 支付时间 | 支付完成时间 |

## 订单状态

| 状态 | 说明 |
|------|------|
| 待支付 | 订单已创建，等待支付 |
| 已支付 | 支付成功 |
| 已完成 | 订单完成 |
| 已取消 | 订单已取消 |
| 已退款 | 退款成功 |

## 订单操作

- **查看详情**：查看订单详细信息
- **申请退款**：符合条件可申请退款
- **下载凭证**：下载订单发票

## 筛选条件

- 时间范围
- 订单状态
- 支付方式

## 最佳实践

::: tip 建议
- 保留订单截图作为凭证
- 定期查看订单历史
- 如有问题及时联系客服
