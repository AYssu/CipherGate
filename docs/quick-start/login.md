# 首次登录

## 登录方式

CipherGate 提供两种登录入口：

### 1. 开发者登录

适用于应用创建者和管理者。

#### 登录步骤

1. **访问首页**
   - 打开平台首页
   - 点击右上角「登录」按钮

2. **输入账号信息**
   - 邮箱：注册时使用的邮箱
   - 密码：设置的登录密码

3. **完成登录**
   - 点击「登录」按钮
   - 进入开发者后台

::: warning 注意
开发者账号需要管理员审批才能使用完整功能
:::

### 2. 应用用户登录

适用于被授权的终端用户。

#### 登录步骤

1. **访问首页**
   - 打开平台首页
   - 点击「应用用户登录」按钮

2. **选择应用**
   - 如果有多个应用，选择要登录的应用
   - 点击应用卡片进入登录

3. **输入账号信息**
   - 邮箱：注册时使用的邮箱
   - 密码：设置的登录密码
   - 验证码：输入图形验证码

4. **完成登录**
   - 点击「登录」按钮
   - 进入应用用户中心

## 登录后功能

### 开发者后台
- [仪表盘](/developer/) - 查看应用概览数据
- [应用管理](/developer/application) - 管理应用配置
- [用户管理](/developer/app-user) - 管理终端用户

### 应用用户中心
- [仪表盘](/portal/) - 查看个人数据
- [会员信息](/portal/membership) - 查看会员状态
- [充值](/portal/recharge) - 会员充值

## 常见问题

### Q: 忘记密码怎么办？
A: 点击登录页面的「忘记密码」链接，通过邮箱重置密码。

### Q: 登录提示账号不存在？
A: 请确认邮箱输入正确，或联系管理员确认账号状态。

### Q: 收到封禁提示？
A: 联系应用管理员了解封禁原因并申请解封。
