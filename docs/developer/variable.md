# 变量管理

变量管理允许您为应用配置自定义变量，用于存储和管理应用相关的配置信息。

## 功能列表

| 功能 | 说明 |
|------|------|
| 创建变量 | 新建自定义变量 |
| 编辑变量 | 修改变量值 |
| 删除变量 | 删除变量 |
| 查看变量 | 查看变量详情 |

## 变量类型

| 类型 | 说明 |
|------|------|
| 字符串 | 文本类型的值 |
| 数字 | 数值类型的值 |
| 布尔 | true/false 值 |
| JSON | JSON 格式的值 |

## 创建变量

### 步骤 1：进入变量管理

1. 登录开发者后台
2. 点击左侧菜单「应用管理」→「变量管理」

### 步骤 2：点击创建

1. 点击「创建」按钮
2. 填写变量信息

### 步骤 3：填写信息

| 字段 | 说明 | 必填 |
|------|------|------|
| 变量名 | 变量的唯一标识 | ✅ |
| 变量值 | 变量的值 | ✅ |
| 变量类型 | 值的数据类型 | ✅ |
| 描述 | 变量的用途说明 | ❌ |

### 步骤 4：确认创建

1. 点击「确定」按钮
2. 变量创建成功

## 使用场景

- 存储 API 密钥
- 配置应用参数
- 管理环境变量
- 存储动态配置

## 最佳实践

::: tip 建议
- 变量名使用有意义的命名
- 敏感信息建议加密存储
- 定期审查变量配置
:::
