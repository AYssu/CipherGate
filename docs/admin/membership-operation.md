# 会员与配额运营

该模块管理平台用户等级、用户会员和额度商品。

## 会员等级

每个等级包含编号、名称、价格，以及应用、卡密、用户注册和流量额度。额度可使用 `-1` 表示不限制。

修改等级不会自动重算所有用户的历史额度。需要调整存量用户时，应在用户会员中单独修改。

## 用户会员

管理员可以调整用户的：

- 会员等级和到期时间。
- 额外应用、卡密、用户和流量额度。
- 余额。

手动发放或充值前应核对用户 ID 和变更原因，避免重复增加额度。

## 额度商品

商品包含编码、名称、类型、额度值、价格和描述。类型包括应用额度、卡密额度、用户注册额度、流量额度和会员升级。

商品会用于余额购买或 Portal 配额产品。修改价格只影响后续订单，不修改历史订单金额。

## 订单管理

管理员订单页展示待支付、已支付、已取消、已退款和失败订单。待支付订单可以手动发放，但只有在确认已实际收款后才能操作。
