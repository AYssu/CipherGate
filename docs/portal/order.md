# 订单历史

订单历史页面展示您的所有购买记录。

## 订单字段

| 字段 | 说明 |
|------|------|
| 订单号 | 唯一订单标识 |
| 商品名称 | 购买的商品 |
| 订单金额 | 支付金额 |
| 支付状态 | 已支付/待支付 |
| 支付方式 | 微信/支付宝/余额 |
| 创建时间 | 下单时间 |

## 订单操作

- **查看详情**：查看订单详细信息
- **下载凭证**：下载订单发票

## 筛选条件

- 时间范围
- 订单状态

## 常见问题

### Q: 如何获取发票？
A: 在订单详情页点击「下载凭证」即可。

### Q: 订单支付失败怎么办？
A: 可以在订单列表重新支付或取消订单重新下单。
