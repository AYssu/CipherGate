# 终端用户管理

终端用户是应用内的账号用户，与卡密用户分开管理。用户可以绑定多个设备，并通过 WebSocket 或 Portal 使用应用。

## 用户信息

可维护用户名、邮箱、手机号、昵称、头像、签名、密码和会员到期时间。列表还展示：

- 登录次数、最后登录时间/IP/归属地。
- 最后登录设备标识。
- WebSocket 在线状态、会话数和在线时长。
- 会员状态、试用状态及到期时间。
- 是否存在被封禁设备。

## 设备绑定

绑定记录包含设备 ID、设备名称、系统、IP、绑定类型、使用次数和最后活跃时间。账号绑定与卡密绑定可能共用设备，发生冲突时第三方 WebSocket 登录会返回 `DEVICE_CONFLICT`。

## 常用操作

- 创建、修改、删除用户和重置密码。
- 延长会员时长，支持批量操作。
- 封禁或解封用户、设备，并填写原因。
- 强制断开用户的 WebSocket 会话。
- 解绑设备；被软删的设备在用户重新登录时可能按服务端规则恢复。

## 自助查询

[终端用户自助查询](/self-service/app-user) 用于用户查看会员到期和绑定状态。自助页面只展示有限信息，不提供管理员级解绑和封禁操作。
