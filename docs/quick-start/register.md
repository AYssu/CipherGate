# 快速注册

## 注册方式

CipherGate 支持两种注册方式：

### 1. 应用用户注册

适用于被应用管理员邀请的终端用户。

#### 注册步骤

1. **获取注册链接**
   - 向应用管理员获取专属注册链接
   - 链接格式：`https://your-domain/register?id=应用ID`

2. **填写注册信息**
   - 用户名：2-50 个字符，支持字母、数字、下划线、中划线
   - 工作邮箱：用于接收验证码
   - 邮箱验证码：6 位数字
   - 登录密码：至少 8 位，需包含字母和数字

3. **完成注册**
   - 点击「注册」按钮
   - 注册成功后可直接登录

::: tip 提示
- 验证码有效期为 60 秒
- 如未收到验证码，请检查垃圾邮件
:::

### 2. 开发者注册

适用于需要创建和管理应用的开发者。

#### 注册步骤

1. **访问首页**
   - 打开平台首页
   - 点击「应用用户登录」或「开发者登录」

2. **创建账号**
   - 在登录弹窗中选择「注册」
   - 填写邮箱、密码等信息
   - 完成邮箱验证

3. **开始使用**
   - 登录后进入开发者后台
   - 可以创建和管理应用
