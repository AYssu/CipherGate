# 应用用户中心（Portal）

应用用户中心是终端用户的自助服务门户。

## 功能列表

| 功能 | 说明 |
|------|------|
| [仪表盘](/portal/) | 查看个人数据概览 |
| [会员信息](/portal/membership) | 查看会员状态 |
| [充值](/portal/recharge) | 会员充值 |
| [订单历史](/portal/order) | 购买记录 |
| [设置](/portal/settings) | 个人信息设置 |

## 登录方式

应用用户通过以下方式登录：

1. **专属链接**：通过应用管理员提供的链接登录
2. **首页登录**：点击首页「应用用户登录」按钮

## 仪表盘

仪表盘展示用户的个人数据：

- 会员状态
- 到期时间
- 设备绑定
- 最近活动
