# 系统配置

系统配置页按标签维护 GitHub OAuth、站点信息、邮件、支付、IP 归属、OAuth 代理和邀请设置。

## GitHub OAuth

配置 Client ID、Client Secret、回调地址和前端地址。Secret 不回显；留空保存时保持原值。

## 站点信息

维护 ICP 备案号、公安备案号和 ICP 许可证号。公开页面使用这些字段展示备案信息。

## 邮件

配置 SMTP 主机、端口、用户名、密码、发件地址和发件人名称，并启用邮件服务。密码不回显，未填写时保持原配置。邮箱验证码依赖该配置。

## 支付

支持易支付协议，配置接口地址、商户 ID、密钥、异步回调和同步跳转地址。Portal 支付还需配置门户回调、同步返回和支付成功跳转地址。

支付回调地址必须能被支付网关公网访问，并与实际域名、HTTPS 和路由配置一致。

## IP 归属

- GeoIP：上传国家/城市数据库并启用。
- ip2region：上传 `ip2region.xdb` 并启用。

页面会展示数据库上传状态和最近错误。登录日志、用户归属和 Portal 控制台使用这些能力解析 IP。

## OAuth 代理

代理支持 HTTP 和 SOCKS5，可配置主机、端口、用户名和密码。HTTP 代理不需要认证时用户名和密码留空；SOCKS5 密码不是 HTTP 代理测试的必要条件。

保存密码后页面不会回显密码。需要删除已保存密码时勾选「清除已保存的代理密码」再保存。测试按钮会展示：

- Google HTTP 状态。
- 通过代理获取的公网 IP。
- `github.com` 连通延迟。
- `api.github.com` 连通延迟。
- 实际测试的代理类型。

容器部署时，代理主机不能写容器自身不可达的 `127.0.0.1`。若代理运行在宿主机，应使用宿主机可达地址或 Docker 网络服务名。

## 邀请设置

配置邀请功能开关、最大邀请人数和每人奖励金额。奖励通过余额或用户额度规则入账，具体展示在用户邀请和余额流水中。
