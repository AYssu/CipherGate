# 内容与运营

内容模块包括平台公告、站内文档、管理端订单和工单。

## 公告

公告包含标题、内容和状态。启用的公告可展示给目标用户。公告与某个应用的客户端公告不是同一份数据，应用公告在应用管理中维护。

## 文档管理

文档按分类组织，文档项包含标题、正文、作者信息、排序、状态和附件。管理员可以：

- 新增、编辑和删除分类。
- 新增、查看、编辑和删除文档。
- 管理附件并记录下载次数。
- 通过 `/admin/docs/view/:id` 查看文档。

文档正文使用站内文档能力发布；VitePress `/docs/` 是本仓库维护的产品使用文档，两者用途不同。

## 管理工单

管理员可以按待处理、处理中、等待回复、已解决和已关闭筛选工单，查看对话、回复、催办和关闭。

处理支付、权限和第三方调用问题时，优先使用订单号、用户 ID、应用 ID、请求 IP 和 traceId 关联日志。

## 管理端订单

管理端订单页用于跨用户核对订单和手动发放。手动发放不是退款功能，也不能替代支付渠道的原始支付凭证。
